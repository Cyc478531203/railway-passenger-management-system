# 高铁列车旅客管理信息系统

这是一个 C++17 控制台课程设计。列车路线为：

`上海 → 苏州 → 南京 → 济南 → 天津 → 北京`

共有 5 个计价区间，每跨一个区间收费 150 元，一等座每张票另加 100 元。列车包含 2 节一等座车厢（每节 5 座）和 3 节二等座车厢（每节 9 座），总容量 37 人。

## 数据结构设计

- 每节车厢使用一个跳表保存旅客，结点按票号有序排列。跳表属于多级链式结构，查询、插入和删除的平均时间复杂度为 `O(log n)`。
- 使用链地址哈希表按身份证后四位建立辅助索引，平均查询复杂度为 `O(1)`。身份证后四位可能重复，因此查询会返回全部匹配记录。
- 使用链表保存售票流水。旅客下车后从车厢跳表和哈希索引中删除，但售票流水继续保留，用于客流和收入统计。
- 座位按乘车区间判断是否冲突。例如某座位已出售“上海→南京”，仍可继续出售“南京→北京”。
- 自动分配座位时，先选择指定席别中当前乘车区间载客量最少的车厢，再选择其中编号最小的空闲座位，使各车厢人数尽量均匀。

## 功能

1. 显示车次、车厢类型、座位容量、全程余票和各相邻区间余票。
2. 查询指定区间和席别的全部可售车厢及座位号。
3. 售票并自动均衡分配车厢；成功后实时显示余票，售罄时推荐其他车次。
4. 根据身份证后四位查询尚未下车的旅客，并说明查询失败原因。
5. 按车站、车厢办理旅客上车。
6. 按车站、车厢显示下车旅客，并从当前旅客结构中删除。
7. 分类统计各站上下车人数、各车厢上车分布和累计收入。

## 编译运行

使用 GCC：

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o train_system
./train_system
```

使用 Visual Studio 开发者命令提示符：

```bat
cl /std:c++17 /EHsc /utf-8 main.cpp
main.exe
```

程序数据保存在内存中，退出后清空，适合作为数据结构课程设计演示。若需要长期保存，可以在此基础上增加文件读写或数据库模块。

## 自动测试

在 PowerShell 中执行：

```powershell
.\tests.ps1
```

测试脚本会使用严格编译选项重新编译程序，并检查初始容量、区间余票、票价、均衡分配、座位分段复用、身份证后四位重复、一等座售罄、上下车、历史统计和非法输入。

## 在 VS Code 中使用

打开本文件所在文件夹后：

- 按 `Ctrl+Shift+B` 可编译程序。
- 打开“终端 → 运行任务”，选择“运行高铁旅客管理系统”可编译并运行。
- 选择“运行自动测试”可重新运行全部自动测试。
